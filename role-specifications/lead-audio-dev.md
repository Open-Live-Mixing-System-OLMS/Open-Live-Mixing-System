# Lead Audio Developer - Open Live Mixer System

## About the Project
We aim to build an open source live audio mixer that can compete with the existing proprietary products. This is a volunteer open source project driven by passion for audio technology and community contribution. However, there are plans for future monetization and you will be at the centre.

## Role Overview
We're looking for an experienced audio developer to lead the technical architecture and implementation of our real-time audio engine. You'll be responsible for designing DSP pipelines, ensuring low-latency performance and helping set technical direction for the project.

## Key Responsibilities
- Design and implement the core audio engine architecture
- Develop real-time audio processing algorithms (mixing, routing, effects)
- Optimize for low-latency performance and minimal CPU usage
- Handle audio I/O, device management, and driver interfacing
- Implement thread-safe audio processing patterns
- Mentor other contributors and review code
- Document technical decisions and API design
- Collaborate with UI/UX designer on audio-visual integration

## Required Skills
- Strong proficiency in real-time audio programming (C, C++, Rust, or similar)
- Deep understanding of DSP fundamentals (filtering, mixing, effects)
- Experience with audio APIs (JACK, ALSA, CoreAudio, WASAPI, or Web Audio API)
- Knowledge of real-time programming constraints (lock-free algorithms, memory management)
- Understanding of audio threading models and callback patterns
- Proficiency with version control (Git) and collaborative development

## Ideal Experience
- Previous work on audio software (DAWs, plugins, live audio tools)
- Experience with audio buffer management and sample rate conversion
- Contributions to other open source audio projects
- Experience with performance profiling and optimization

## Nice to Have
- Familiarity with audio networking protocols (AES67, Dante, AVB)
- Knowledge of audio metering and visualization
- Experience with CI/CD for audio applications
- Understanding of accessibility in audio software

## What We Offer
- Creative freedom to shape the technical direction
- Opportunity to build something meaningful for the audio community
- Collaboration with passionate contributors
- Portfolio-worthy project for your GitHub profile
- Flexible commitment - contribute at your own pace

## Time Commitment
This is a volunteer position. We're looking for someone who can dedicate at least a couple of hours per week to the project, with understanding that open source timelines are adaptable.

- Availability and preferred communication style
