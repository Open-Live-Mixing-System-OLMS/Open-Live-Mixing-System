# UI/UX Designer - Open Live Mixer System

## About the Project
We aim to build an open source live audio mixer that can compete with the existing proprietary products. This is a volunteer open source project driven by passion for audio technology and community contribution. However, there are plans for future monetization and you will be at the centre.

## Role Overview
We're seeking a UI/UX designer to create an intuitive, responsive interface for professional and enthusiast audio users. You'll be responsible for the complete user experience—from workflow design to visual interface—ensuring the mixer is both powerful and accessible.

## Key Responsibilities
- Design the overall user experience and interaction patterns
- Create wireframes, mockups, and prototypes for the mixer interface
- Design visual elements (controls, meters, channel strips, routing views)
- Develop a design system for consistent UI components
- Ensure accessibility and usability for diverse users
- Conduct user research and gather feedback from audio community
- Collaborate with lead developer on technical feasibility
- Create design documentation and guidelines for contributors

## Required Skills
- Strong UI/UX design fundamentals (layout, typography, color, hierarchy)
- Proficiency with design tools
- Understanding of interaction design and user workflows
- Ability to create responsive, scalable interfaces
- Experience designing for desktop applications or complex web apps
- Basic understanding of front-end constraints and possibilities
- Strong communication skills for explaining design decisions

## Ideal Experience
- Previous work on audio, music, or creative software interfaces
- Understanding of audio mixing workflows and terminology
- Experience designing real-time, data-dense interfaces
- Knowledge of accessibility standards (WCAG, keyboard navigation)
- Familiarity with design systems and component libraries
- Experience conducting user testing and iterating on feedback
- Portfolio demonstrating complex interface design

## Nice to Have
- Familiarity with professional audio hardware (mixing consoles, interfaces)
- Basic front-end skills (HTML/CSS) to prototype ideas
- Experience with motion design for UI animations
- Understanding of skeuomorphic vs. flat design in audio contexts
- Knowledge of dark mode and theme design
- Experience with open source design collaboration

## Understanding of Audio Mixing
You don't need to be an audio engineer, but familiarity with these concepts helps:
- Channel strips, faders, pan controls, and routing
- Metering (VU, peak, RMS, loudness)
- Effects sends/returns and aux buses
- Signal flow and gain staging
- Common user workflows in live mixing

## What We Offer
- Creative control over the visual direction and UX
- Opportunity to shape how audio professionals interact with software
- Collaboration with passionate audio and development community
- Portfolio project showcasing your work to the audio tech world
- Flexible commitment and creative freedom

## Time Commitment
This is a volunteer position. We're looking for someone who can dedicate at least a couple of hours per week to the project, understanding that open source work adapts to your schedule.
